1. 项目是什么

核心主张：one cat, one profile（一猫一档）——每条喂养记录、体重曲线、疫苗提醒甚至 AI 聊天上下文都按 catId 隔离，多猫家庭永不串档。所有数据存本机，无账号无云端无遥测。

3. 安装与上手

  1. GitHub Releases 下载：Android 装 APK；Windows 解压 zip 运行 ecat.exe。
  2. 首次启动 3 页引导创建第一只猫档案。
  3. 日常：三合一快捷录入（喂食/体重/健康）一键常用量，大按钮少打字。
  4. AI 助手：设置里填 OpenAI 兼容 API key（BYOK）。
  5. 换机：旧机「导出 JSON」→ 新机「导入」全量迁移。

4. 从源码构建

# 环境：Flutter SDK（Dart >= 3.12.2）+ Android SDK / Windows 桌面工具链
git clone https://github.com/lvliang666666/ecat.git && cd ecat
flutter pub get
flutter test                # 39 用例
flutter build apk --release        # Android → build/app/outputs/flutter-apk/
flutter build windows --release    # Windows → build/windows/x64/runner/Release/
Windows 构建两坑：① 必须开启开发者模式，否则插件符号链接创建失败、构建静默挂起；② 国内网络设 PUB_HOSTED_URL=https://pub.flutter-io.cn 与 FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn。

5. 移植与数据迁移

  • 开发环境移植：装 Flutter → clone → pub get → test → build。
  • 用户数据：App 内一键 JSON 导出/导入（含全部猫档案与记录）。
  • 备份优先级：用户导出的 JSON（不可再生）> 源码（GitHub 已异地）。

6. 技术亮点

  • 猫中心数据隔离：每条记录带 catId，删猫级联清理其日志/提醒/AI 会话——零孤儿数据；
  • 可靠本地通知：Android 用 inexactAllowWhileIdle（免精确闹钟权限）+ 每日重复匹配；Windows 预排 7 天滚动窗口；开机广播恢复 + 错过补发 SP 标记去重；
  • R8 安全发版：core library desugaring + 通知插件 keep 规则——用 mapping.txt 验证 receiver 保持原名，避开「release 版通知静默死亡」经典坑；
  • 自定义触感系统：CuteTap 包装器（按压缩放 0.96 + selectionClick）全组件覆盖；吞手势的 Material 组件（导航栏/FAB）重画保反馈一致。

7. FAQ

Q1：支持 iOS 吗？

当前 Android + Windows 双端，iOS 未适配。

Q2：多只猫数据会混吗？

不会——catId 全链路隔离是本项目的核心设计，删猫级联清理。

Q3：Windows 构建卡住不动？

开开发者模式（系统设置 → 开发者选项），否则符号链接失败静默挂起。

Q4：release 版通知不响？

检查 keep 规则是否在（com.dexterous.** 与 gson）——R8 混淆掉 receiver 类名是经典坑，本项目已用 mapping.txt 验证。
